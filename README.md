# Nihongo — learn Japanese from zero

A free, Apple-style web app for English speakers starting Japanese from scratch.

Path: Hiragana → Katakana → Numbers → Greetings & Phrases → Core Vocabulary.
Each step has flashcards (with 🔊 browser text-to-speech), a chart/list, and a quiz (multiple choice, reverse choice, type-the-romaji). Progress is saved in localStorage — no accounts.

All lesson content is original and lives in `src/lib/data.ts`.

```bash
npm install && npm run dev
```

Next.js (App Router) + TypeScript + Tailwind. MIT licensed.
